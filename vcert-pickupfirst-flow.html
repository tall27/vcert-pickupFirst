VCert pickupFirst Decision & Central Platform Authority Flow

Comprehensive architectural decision tree for zero-touch cluster convergence and automated revocation/retirement reconciliation across CyberArk Certificate Manager SaaS, NGTS, and Venafi TPP. 

flowchart TD
    Start(["vcert run -f playbook.yaml
(Automated Daily Cron)"]) --> Q1{"pickupFirst: true
in playbook request?"}

    Q1 -- "No" --> Legacy["Legacy Standalone Flow:
Inspect local disk NotAfter date
via renewBefore threshold"]
    Q1 -- "Yes" --> Q2{"Query CyberArk / Platform
(LocateLatestCN):
Active matching cert found?"}

    %% Zero active certs branch (Contract 001 / Robert's case)
    Q2 -- "No (0 Active Certs in CyberArk)" --> Q_Local{"Does local host already
have a cert file installed
on disk (/etc/...)?"}
    Q_Local -- "No (Empty disk)" --> Day0["Day-0 Bootstrap:
Enroll initial cert with CA,
vault key & install locally"]
    Q_Local -- "Yes (Local cert exists!)" --> NIST["Contract 001 (NIST Central Authority):
Installed cert is UNAUTHORIZED
(Retired or Revoked in CyberArk)"]
    NIST --> AuthEnroll["Authoritative Re-Enrollment:
Bypass local date check, enroll
fresh cert + key from CA, update files
& reload service (Zero-Touch!)"]

    %% Active cert exists branch (Cluster convergence)
    Q2 -- "Yes (Active Cert Exists)" --> Q_Match{"Does local installed
thumbprint match
platform thumbprint?"}
    
    Q_Match -- "Thumbprint Matches" --> Q_Renew{"Is local certificate
within renewBefore
window?"}
    Q_Renew -- "No (Healthy)" --> FastExit["Healthy State:
Exit in <1s with 0 actions
(Sub-second Idempotent Cron)"]
    Q_Renew -- "Yes (Renewal Due)" --> StdRenew["Standard CA Renewal:
Enroll renewed cert from CA,
update files & reload service"]

    Q_Match -- "Thumbprint Mismatches" --> Q_Newer{"Is platform cert
NEWER than local?
(ValidTo > NotAfter)"}
    Q_Newer -- "No (Platform Older)" --> RefuseDowngrade["Refuse Downgrade:
Leave local files intact;
log warning & exit clean"]
    Q_Newer -- "Yes (Platform Newer)" --> Q_Key{"Is vaulted private key
available from platform
(csr: service / DEK)?"}

    Q_Key -- "Yes (Vault key available)" --> Converge["Cluster Follower Convergence:
Download cert + vaulted key,
install locally (0 CA requests!)"]
    Q_Key -- "No (Cert-only pickup)" --> Q_LocalKey{"Does local disk key
match cert public key
(tls.X509KeyPair)?"}

    Q_LocalKey -- "Key Mismatch" --> MismatchSafeguard["Key Mismatch Safeguard:
Reject wrong key from disk;
fall through to enroll fresh pair"]
    Q_LocalKey -- "Matches" --> AttachKey["Attach Local Key:
Install cert + verified key,
reload service"]
